# 🦕 Dino-Runner

A fun game project built with HTML, CSS, and JavaScript. Dodge obstacles and collect points as long as you can—just like the classic T-Rex runner game!

## 🚀 Demo

Play the game right now at:  
[https://dino-runner-demo.netlify.app/](https://dino-runner-demo.netlify.app/)

## 💻 Run Locally

1. **Clone or download** the repository:  
   `git clone https://github.com/divyanshchandel16/Dino-Runner.git`
2. **Open** `index.html` in your browser.

## 🔨 Built With

- **HTML**
- **CSS**
- **JavaScript**
